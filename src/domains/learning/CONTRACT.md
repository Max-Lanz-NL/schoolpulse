# Learning contract

- **Purpose:** homework, assignments, deadlines, submissions and basic learning files.
- **Sources:** `assignments`, `assignment_submissions`, `file_assets`; `document_versions` supports file history.
- **Roles:** teachers manage assigned groups; pupils view and submit their own work; guardians read only when explicitly permitted.
- **Reads:** scoped assignments, submissions and safe file metadata.
- **Writes:** assignment workflow, own submission and authorised file upload.
- **Dependencies:** Identity, School and People.
- **Outside 1.0:** LMS courses, plagiarism detection, AI tutor and OneDrive.
